# 演示脚本

1. 注册一个新用户并完善学校、专业、目标城市与目标岗位。
2. 上传 `tests/fixtures/resume-demo.md`；展示识别出的技能及原文证据，再点击确认。
3. 录入 `tests/fixtures/job-demo.txt`；展示 REQUIRED/PREFERRED 分类、总分和逐项计算。
4. 在 Career Agent 中询问“我适合这个岗位吗？”；观察公开的 tool_call、回答和 chunk 引用。
5. 开始模拟面试；第一题完整回答，第二题故意遗漏关键点以触发一次追问，最后展示报告。

简历描述建议（只在你实际跑通后使用）：

> 设计并实现基于 Spring Boot 4、Spring AI 2 与 Vue 3 的 AI 求职智能体平台，以领域工具调用串联结构化简历、JD 分析、确定性技能匹配、可引用知识检索和模拟面试；通过用户级资源隔离、证据模型、SSE 流式状态与无模型降级提升可解释性和可靠性。
