# 演示脚本

1. 首页点击“在线体验”，直接生成一次性示例用户；正式演示也可注册新用户。
2. 上传 `tests/fixtures/resume-demo.md`；展示识别出的技能及原文证据，再点击确认。
3. 录入 `tests/fixtures/job-demo.txt`；展示 REQUIRED/PREFERRED 分类、四维分、置信度和逐项证据。强调分数是证据契合度，不是录用概率。
4. 在 Career Agent 中询问“我适合这个岗位吗？”；观察公开的 tool_call、回答和 chunk 引用。
5. 开始模拟面试；第一题完整回答，第二题故意遗漏关键点以触发一次追问，最后展示报告。

简历描述建议（只在你实际跑通后使用）：

> 设计并实现基于 Spring Boot、Spring AI 与 Vue 3 的可解释 AI 求职智能体，以领域工具调用串联简历解析、JD 分析、四维技能匹配、可引用知识检索与模拟面试；通过用户级资源隔离、PostgreSQL/Redis 生产适配、SSE 状态流、模型超时降级与 CI 流水线提升可靠性和可部署性。

## 面试时怎么讲

- **为什么不用大模型直接评分？** 可重复性和可解释性更重要，所以模型只抽取/解释，规则服务负责唯一真值。
- **为什么分数不会总是 100？** 提到技能只完成覆盖维度，仍需证据、熟练度和项目相关性。
- **模型挂了怎么办？** 请求超时后自动切到确定性回答，核心匹配与知识引用仍可使用。
- **本地和生产如何兼顾？** H2 实现零配置体验，属性切换到 PostgreSQL/Redis，领域层不变。
- **下一步是什么？** 向量 + 关键词混合检索、对象存储、规范化表仓储和真实评测集。
